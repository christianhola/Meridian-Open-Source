## Prompt de adaptación a producto SaaS

> Adapt this warm editorial system to a B2B SaaS workspace. Preserve the #fdfcfc eggshell canvas, #f5f3f1 taupe surfaces, #ebe8e4 hairlines, Waldenburg 300 display typography, Inter 400/500 body typography, and 4px spacing base. Use black filled pill CTAs and reserve violet/orange exclusively for product visualization. Add clear data density, keyboard focus, empty/error/loading states, responsive max-width 1280px layout, and accessible contrast.

## Prompt de auditoría

> Audit this interface against the Refero ElevenLabs reference. Report exact deviations in color roles, font weight, tracking, line height, radius, section rhythm, borders, elevation, responsive behavior, and CTA hierarchy. Separate observed facts from recommendations and propose token-level fixes before component-level changes.
